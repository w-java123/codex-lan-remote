# Codex LAN Remote

[![发行版](https://img.shields.io/badge/GitHub-发行版-green)](https://github.com/w-java123/codex-lan-remote/releases/latest)

在 Android 手机上继续操作电脑里的 Codex：发送任务、查看进度、处理审批，离开电脑也能跟进工作。

项目由 **Android 客户端**和 **Windows「手机连接」插件**组成，支持局域网直连和 EasyTier 异地组网。

[下载安装包](https://github.com/w-java123/codex-lan-remote/releases/latest) · [电脑端使用指南](docs/电脑端插件使用指南.md) · [原项目](https://github.com/fabulouszcc/codex-lan-remote)

## 解决什么问题

- **离开电脑后，任务进度难以跟进**：手机同步查看聊天、任务状态和工具活动，完成或需要审批时接收通知。
- **需要回到电脑才能继续操作**：在手机发送或追加指令、中断当前任务、切换聊天，并选择电脑实际支持的模型和思考强度。
- **手机与电脑不在同一网络**：通过内置 EasyTier 组网连接，也可以沿用自己已有的组网服务。
- **连接与配对配置繁琐**：电脑提供统一设置页，手机扫码配对；使用内置 EasyTier 时可同时导入入网参数，由 DHCP 自动分配手机地址。

## 功能介绍

以下包含主分支的最新功能，下载安装时请以对应 Release 的版本说明为准。

| 功能 | 使用体验 |
| --- | --- |
| 聊天同步 | 优先同步当前聊天，随后在后台缓存其他聊天；按桌面分组展示，保持置顶聊天及顺序，支持搜索和右侧记录栏定位 |
| 任务操作 | 手机新建项目内的聊天，发送与追加指令、中断任务；运行时发送的消息先进先出排队，可查看和移出队列 |
| 离线语音 | 空输入框长按按钮说话，识别文字直接填入草稿；首次确认下载约 42 MB 中文模型，之后无需联网识别，音频不上传 |
| 工具与审批 | 工具调用及运行中的文件变更折叠展示；在手机处理审批、直接填写问题卡片，任务完成或需要处理时接收通知 |
| 文件与图片 | 用户附件整合进消息气泡，任务结束后的产出文件以卡片展示；点击后才请求文件内容，优先保障消息同步 |
| 文件预览 | 查看图片、文本、Markdown 和常用 Office 文件；聊天及 Markdown 表格支持横向滑动，Word 保留段落、表格和基础公式结构；PDF 支持连续上下翻页和双指缩放，文件可保存到本地或交给其他应用打开 |
| 连接管理 | 局域网直连、已有组网和内置 EasyTier；记忆已验证的局域网地址，连接失败时尝试历史地址；扫码配对并导入组网参数，保存为内置 EasyTier 模式后再次进入自动组网 |
| 显示与提醒 | 黑色、明亮模式，可按所选城市的日出日落自动切换；顶部双圆弧展示可用的账户额度信息，连接圆点区分状态 |
| 更新检测 | 设置内手动检查版本；主版本或次版本升级时自动提醒，支持现在更新、下次提醒或忽略该版本，并提示电脑插件更新 |

文件预览需要电脑在线且仍保留原文件。首次点击会通过已配对连接获取内容，不会随聊天记录自动下载所有附件。

离线语音模型按需下载，不包含在 APK 中；下载页面提供进度、取消和失败重试，设置中可查看模型状态。语音输入仅在应用前台使用麦克风。

## 使用条件

| 设备 | 要求 |
| --- | --- |
| 电脑 | Windows x64，已安装 Codex 桌面端 |
| 手机 | Android 9 或更新版本，ARM64 |
| 网络 | 同一局域网，或通过 EasyTier 等方式互通 |

远控聊天时，电脑需要保持开机，Codex 桌面端需要运行，并允许手机访问对应聊天。

## 安装与连接

### 1. 安装电脑插件

从 [GitHub 最新发行版](https://github.com/w-java123/codex-lan-remote/releases/latest) 下载并运行 `Codex-LAN-Windows-x64-Setup.exe`。安装后打开「手机连接设置」，按页面引导配对。

安装成功后，桌面和开始菜单会出现两个快捷方式。

- **手机连接设置**：首次使用时配置网络、保存并启用连接，再生成二维码供手机扫码配对。
- **Codex 手机共享控制**：日常启动 Codex 和手机连接网关。如果已用普通入口打开 Codex，先等当前任务结束，从桌面菜单正常退出，再用这个快捷方式打开。

Windows 安装器支持只安装 Microsoft Store 版 Codex 的电脑。安装器会读取 Windows 已注册的 Codex 安装路径，无需先打开 Codex 生成本地 CLI 目录。

同一发行版提供 Android APK 和校验清单。已经安装旧版的用户先覆盖安装支持增量更新的版本。后续在电脑的「手机连接设置」或手机的「检测更新」里检查新版。[发行版与增量更新](docs/发行版与增量更新.md)

### 2. 选择连接方式

| 连接方式 | 适用场景 | 配置方法 |
| --- | --- | --- |
| 局域网直连 | 手机和电脑连接同一路由器 | 选择「局域网 / 已有网络」，选中电脑的 Wi-Fi 或以太网地址 |
| 已有组网 | 已使用 EasyTier 或其他组网工具 | 手机先加入对应网络，再在「局域网 / 已有网络」中选择电脑的虚拟网卡地址 |
| 内置 EasyTier | 希望由插件和手机 App 管理组网 | 选择「内置 EasyTier」，填写网络名称、密钥、电脑虚拟 IPv4/前缀及组网节点 |

点击「保存并启用」。内置 EasyTier 创建虚拟网卡时，如需管理员权限，使用设置页的「请求管理员启动」，并确认 Windows 提示。

插件只管理自己启动的 EasyTier 实例，已有系统组网服务由你原来的工具管理。

### 3. 安装手机 App 并扫码配对

1. 从同一 Release 下载 Android APK 并安装。
2. 在电脑设置页生成配对二维码。
3. 手机首次打开 App，点击「扫码添加电脑」，扫描二维码；也支持从图片识别或粘贴完整配对信息。
4. 确认配对。使用内置 EasyTier 时，确认导入网络参数并允许 Android VPN 授权，手机自动获取虚拟地址后连接电脑。
5. 连接成功后选择聊天，即可查看记录、发送任务和处理审批。

已有组网模式只完成远控配对，不会导入或接管外部组网配置。

### 4. 日常使用

- 在手机顶部切换连接方式，在设置中修改 EasyTier 参数。
- 局域网地址会保存在本机加密配对记录中。连接失败时，只会尝试同一电脑的历史地址，并核对配对证书；不会自动重发尚未确认的任务。
- 点击项目文件夹旁的「＋」创建该项目的新聊天。输入框底部的「排队／插话」可切换发送模式：排队会等待当前任务完成，插话会立即补充指令；点击排队提示可查看或移出消息。没有正在执行的任务时正常发送，输入框为空且任务进行中时显示停止按钮。
- 输入文字后按钮切换为发送箭头。输入框为空时长按按钮可语音输入，识别文字直接回填输入框，不自动发送。首次使用弹出中文离线模型下载提示（约 42 MB），确认后下载，支持取消和失败重试；也可在设置中查看模型状态。下载完成后识别无需联网，音频不上传。麦克风可选择「仅在使用应用时允许」，App 退出前台即停止录音。下载提示和输入界面随明亮／深色模式适配。
- 因额度耗尽、速率限制或上下文超限而中断时，手机显示对应提醒。实际发送与排队执行仍需电脑 Codex 在线且聊天已就绪。
- 通过模型菜单调整电脑支持的模型和思考强度，通过右侧记录栏快速定位聊天内容。
- 点击消息中的附件卡片加载文件；预览页的更多菜单可保存到本地或使用其他应用打开。
- 在设置的「UI 显示模式」中选择黑色或明亮模式，也可开启随日出日落自动切换。
- 手机在「检测更新」检查新版，电脑在「手机连接设置 → 检查更新」检查新版。匹配到增量包时会优先下载增量。
- 首次启动可按引导允许本应用安装更新，也可暂时跳过，之后在「检测更新」中开启；下载后的安装仍需由你确认。
- 为 App 开启通知权限；如需顶部横幅，在系统设置中开启悬浮通知，勿扰模式会影响提醒。
- 登录自启动默认关闭。需要时，打开「手机连接设置 → 通用设置」，勾选「登录 Windows 时启动 Codex 手机共享控制」，然后保存。Windows 会将它加入任务管理器的「启动应用」，下次登录账户时自动启动。
- 不再使用的手机可在电脑设置中撤销授权。

配对二维码包含连接凭据，内置 EasyTier 二维码还包含组网密钥，请只向自己的手机展示。

## 从源码编译

安装包以 Releases 标注的版本为准；需要源码中的最新功能时，可自行构建。

### Windows 插件

需要 Windows、Node.js 24 和 npm。打包脚本会下载并校验固定版本的依赖。

```powershell
npm ci
npm test
.\scripts\build-desktop-plugin.ps1
```

生成的插件目录和 ZIP 位于 `.local/releases/`。解压后的安装方式与上文一致。

### Android App

需要 JDK 17、Gradle 8.9 和 Android SDK 35。可指定已安装的工具路径：

```powershell
.\scripts\build-android.ps1 `
  -SdkPath "C:\Android\Sdk" `
  -JavaPath "C:\Java\jdk-17" `
  -GradlePath "C:\Gradle\gradle-8.9\bin\gradle.bat"
```

脚本会准备固定版本的 EasyTier 原生库、运行状态层测试，并将 APK 输出到 `.local/releases/`。自行构建使用本机签名；覆盖安装旧版需要使用同一签名。

本机配置、签名文件、证书、组网密钥及构建产物均不应提交到仓库。
