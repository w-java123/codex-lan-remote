# 发行版与增量更新

GitHub fork 的公开 Release 同时提供 Android 完整 APK、Windows 完整安装程序和 SHA256SUMS.txt。使用形如 `v0.5.1` 的发行标签。发行说明包含以下元数据，版本以本次发行包内的实际版本为准。

```text
<!-- codex-lan-update: {"androidVersion":"0.5.0-memoryfix.21","desktopVersion":"0.5.1"} -->
```

Android 的 AndroidManifest 版本号由 Gradle 的 `versionCode` 与 `versionName` 提供。保持原应用 ID 和签名，只有 Android 功能有更新时才提高它的版本。Windows 运行时版本在 `desktop/release.json`，保持插件缓存使用原版本目录。

打包本次完整包后，用下面的生成器为计划支持的每个旧版生成一份增量。

```text
python scripts/build-apk-delta.py previous.apk current.apk release-directory
python scripts/build-windows-delta.py previous-bundle.zip current-bundle.zip release-directory
```

Windows 构建脚本的 `-PreviousBundleDirectory` 接受上次打包保存的解包目录。启动器源文件没有改动时会校验并复用上次编译的二进制。运行时之外的依赖、启动器或脚本变更需要完整安装包。增量基线或摘要不匹配时，更新界面可打开完整包发行页。

首次安装和从旧更新器迁移都需要完整包。之后 Android 在「检测更新」使用可匹配的差分并交给系统确认安装，Windows 在「手机连接设置」检查更新。配对与配置保留在应用原有数据目录。
